# מחולל דו״ח חברתי – התחדשות עירונית

כלי עזר עצמאי לכתיבת דו״ח חברתי במיזמי התחדשות עירונית, לפי **מדריך להכנת דו״ח חברתי במיזמי התחדשות עירונית – גרסה 3.0** של הרשות הממשלתית להתחדשות עירונית. *אינו כלי רשמי של הרשות.*

**לשימוש:** https://romangash-star.github.io/social-report/

## מה הכלי עושה
- מפת מתחמי הפינוי־בינוי המוכרזים (שכבת משרד הבינוי והשיכון) – בחירת מתחם או כתובת על המפה
- מילוי אוטומטי ממקורות פתוחים: הלמ״ס (מפקד 2022, אזורים סטטיסטיים, מדד חברתי־כלכלי), מאגר מתחמי ההתחדשות, מינהל התכנון, משרדי החינוך והתחבורה, OpenStreetMap, מרחקי הליכה
- טופס מודרך לפי פרקי המדריך, סקר דיירים, המלצות, הערכת חלופות וגאנט
- הפקת דו״ח מצב קיים / הערכת חלופות / דו״ח מלא – ייצוא ל־Word, HTML והדפסה

## פרטיות
הכלי רץ כולו בדפדפן. נתוני הפרויקט נשמרים רק בדפדפן של המשתמש (ובקובץ גיבוי שהוא מוריד) – לא נשלחים לשום שרת. השאילתות למקורות הפתוחים כוללות רק כתובות ומיקומים.
